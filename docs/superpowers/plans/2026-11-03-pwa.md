# App instalável — plano de implementação

Objetivo aprovado: manter o site e acrescentar instalação como PWA, com identidade atual e orientação offline.

Arquitetura: manifesto e PNGs em public, service worker sem cache de consultas ou HTML dinâmico, instalação progressiva no rodapé. Sem dependências novas nem alterações no adaptador Cloudflare.

- [x] Criar manifesto com id/start_url/scope na raiz, ícones comuns e maskable com área segura, metadados Apple.
- [x] Registrar worker somente em produção e contexto seguro. Cache exclusivo da página offline; navegação online permanece network-first. POST/API/subrecursos passam direto. Atualização aguarda fechamento das abas, sem recarregar formulários.
- [x] Adicionar ação de instalação quando o navegador disponibilizar prompt; instruções manuais para os demais e ocultação em modo instalado. Aviso acessível de conexão perdida.
- [x] Testar worker offline/online, cache isolado, prompt cancelado/aceito/falho, modo instalado e ausência de suporte. Validar TypeScript, build e assets publicados.
- [x] Documentar publicação HTTPS, limites de voz/offline e verificações nos celulares. Gerar patch incremental com PNGs e commits de Ana Ferreira.

Riscos a verificar: não armazenar preços antigos, não interceptar chamadas de servidor, não perder formulários na atualização, não prometer instalação quando não suportada, não depender de fontes externas na página offline.
